# Партнёрская программа

## Самостоятельная регистрация

Пользователь открывает «Настройки → Стать партнёром» внутри Telegram. После проверки подписи Telegram видит предложение создать кабинет. Только нажатие «Создать кабинет и получить промокод» создаёт постоянную запись в Netlify Blobs (`plan-d-partners`, strong consistency).

Код закрепляется за проверенным числовым Telegram ID. Повторная регистрация выдаёт тот же код, а другой пользователь не может получить чужой кабинет. Токен и ID не выдаются клиенту. Пользователь может копировать код и ссылку на сайт с `?promo=КОД`; на странице подписки код из ссылки подставляется в поле и проверяется сервером. Клиент не может назначить свою скидку.

## Активация на Netlify

Нужна одна серверная переменная в Netlify → Environment variables (Functions): `TELEGRAM_BOT_TOKEN` — токен @d_plan_bot из BotFather. Не добавлять его в frontend, Git или чат. После добавления требуется новый deploy. Список разрешённых партнёров `PLAN_D_PARTNERS` больше не нужен.

Netlify Blobs подключается средствами Netlify в развёрнутых функциях. Нужна доступность Blobs на аккаунте; текущие лимиты и стоимость проверяются в Netlify. Локальный `npm start` обслуживает статику; для локальных функций нужен Netlify Dev. Для установки зависимостей используйте `npm ci`.

Отдельный URL кабинета: `/?partner=1`. В обычном браузере без проверенного Telegram initData он не авторизует пользователя. На сайте нет пользовательской кнопки «Кабинет партнёра», есть осознанный вход через «Стать партнёром» в настройках.

## Что пока не подключено

Условия на экране: 2 дня бесплатно; 2667 ₽/неделю без кода; фиксированные 800 ₽/неделю по действующему коду, скидка 70%. Доля партнёра 400 ₽ ДО комиссий и налогов — предлагаемые условия, не гарантированная чистая выплата.

Платежи, привязка промокода к покупке, реальный пробный период, транзакции, возвраты и выплаты пока отсутствуют. Кабинет сообщает, что статистика недоступна. Создание кабинета и проверка кода не дают оплаченный доступ. Для цифрового доступа внутри Telegram необходимо отдельно подключить Stars и определить период подписки и цену в Stars. Рублёвые условия пока не являются платёжным счётом.

Партнёр сам выбирает код: 3–24 символа A–Z, 0–9, _ или -. Регистр нормализуется. Занятость резервируется атомарно через onlyIfNew. В кабинете код можно изменить; старые коды и ссылки остаются привязаны к тому же партнёру. При ошибке занятости или формата поле сохраняется для исправления.

Кабинет разделён на «Обзор», «Промокод», «Выплаты». Доступны копирование кода, ссылки и текста рекомендации, обновление данных. Статистика продаж отображает недоступность данных до подключения биллинга; запрос вывода заблокирован и на клиенте, и сервером (409 payments_not_connected). Заявки и фиктивные суммы не создаются.
