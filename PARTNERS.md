# Партнёрский кабинет — подключение

Пользовательский сайт не содержит кнопки входа в кабинет. Отдельный адрес: `https://preeminent-sprinkles-87237a.netlify.app/?partner=1`.

Для Telegram используйте Main Mini App link `https://t.me/d_plan_bot?startapp=partner` ПОСЛЕ настройки Main Mini App в BotFather. Одна настройка Menu Button сама по себе не подтверждает доступность startapp-ссылки. Прямой адрес в обычном браузере не авторизует партнёра.

Netlify Functions проверяют HMAC подпись Telegram initData, срок один час и разрешённый Telegram user ID. Значения initDataUnsafe не используются сервером для выдачи доступа. Секретный URL не является механизмом авторизации.

В Netlify → Environment variables (scope Functions) нужны:

- TELEGRAM_BOT_TOKEN — секрет токена существующего бота. Не коммитить и не отправлять в чат.
- PLAN_D_PARTNERS — серверная конфигурация партнёров, например `[{"telegram_id":123456789,"code":"ANNA70"}]`. ID — числовой ID, не username. Пример вымышленный. Коды: 3–32 заглавных латинских символа, цифры, _ или -. Партнёров добавляет владелец; саморегистрации и произвольного назначения скидки нет.

После добавления переменных нужен новый deploy. Без настроек endpoint отвечает 503; без валидной подписи 401; для неприглашённого пользователя 403. Промокод проверяется сервером, не выдаёт оплаченный доступ сам по себе.

## Цена и ограничения

Предлагаемые условия: 2 дня бесплатно; 2667 ₽/неделю без кода, фиксированные 800 ₽/неделю по действующему коду со скидкой 70% (округлённая базовая цена). По 400 ₽ владельцу и партнёру ДО комиссий и налогов. Повторяющиеся комиссии и окончательные партнёрские условия ещё требуют утверждения. До начала продаж базовая цена должна быть реальной, а условия прозрачными.

Платёжного провайдера, реального учёта пробного периода, биллинга, привязки покупок, базы транзакций и выплат пока нет. Кабинет не изображает нулевую статистику как проверенную: данные недоступны до подключения платежей. Для цифровой услуги внутри Telegram требуется отдельно реализовать Telegram Stars; рублёвая цена не является реализованным счётом Stars. Автоматическое деление денег не подключено. Будущий сервер должен хранить проверенные платежи, возвраты и начисления, обрабатывать вебхуки идемпотентно и рассчитывать выплаты по партнёрскому договору.
