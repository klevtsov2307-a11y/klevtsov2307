# План Д · Аффирма

Текущая версия: готовая история «Моя вилла у моря», 18:21. Две предоставленные пользователем части объединены в один MP3 без повторного сжатия. Плеер: пауза, перемотка на 15 секунд, выбор скорости, сохранение места на устройстве и скачивание MP3. Конструктор временно скрыт; его материалы сохранены в content.js.

Node.js 22+: `npm start`, порт 3000 (переопределяется PORT). `npm test` проверяет сохранённые материалы конструктора. Для Netlify: publish directory `public`, без сборки; настройки в netlify.toml. Аудио расположено в public/audio/villa-sea.mp3. Локальный сервер поддерживает частичные запросы аудио.

Telegram открывает опубликованный HTTPS-адрес через Menu Button. Фоновое воспроизведение и поведение блокировки экрана необходимо проверять на реальных устройствах. API озвучки не подключён. Ключи не нужны для прослушивания готового MP3 и не должны попадать в клиентский код.

## Оболочка приложения
Приветствие с локальным профилем или гостевым режимом, четыре раздела нижнего меню, категории, избранное, изменение имени, настройки громкости и скорости, таймер сна, сохранение позиции. Аудио не пересоздаётся при переходах. Telegram first_name используется только для заполнения поля; серверной проверки initData, регистрации аккаунтов и синхронизации пока нет. Таймер зависит от выполнения JavaScript в клиенте и требует проверки в фоне на телефоне.

Обновлённая главная: собственная SVG-иллюстрация виллы (public/villa.svg), отметка настроения и заметка благодарности за текущий день, история времени прослушивания по дням. Данные локальные, на сервер не отправляются. История отражает время активного плеера, а не доказанное внимание слушателя.

## Образы твоего дня
В истории «Моя вилла у моря» есть альбом из восьми авторских SVG-иллюстраций. Доступны миниатюры, стрелки, свайп по изображению, скрытие и восстановление карточек. Фото JPG/PNG/WebP/AVIF до 12 МБ перед сохранением уменьшаются до 1200 px и преобразуются в JPEG. Замены сохраняются в localStorage только на устройстве; при ошибке квоты приложение сообщает о ней и сохраняет предыдущее состояние. Картинки не меняют озвученный текст. Кнопка в конце открывает плеер и запускает историю; автозапуск может потребовать дополнительного нажатия на некоторых клиентах.
