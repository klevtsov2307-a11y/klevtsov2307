# План Д · Аффирма

MVP Telegram Mini App: случайный день, конструктор из 16 часов по 4 варианта, сохранение выборов в localStorage, чтение текста, экспорт .txt, пробная озвучка средствами устройства и плеер для локального аудио.

## Запуск

Node.js 22+; внешних npm-зависимостей нет.

```sh
cd /workspace/klevtsov2307
npm start
```

Порт 3000, override: `PORT=8080 npm start`. Проверка: `curl --fail http://127.0.0.1:3000/health`. Тесты: `npm test`.

## Telegram

Для реального открытия Mini App нужен опубликованный HTTPS-адрес. В BotFather создайте бота и задайте URL через настройку Menu Button / Web App. Токен бота этому статическому приложению не нужен. Серверная авторизация и обработка initData в MVP отсутствуют: здесь нет аккаунтов, платежей и отправки персональных данных на сервер. Telegram SDK необязателен для работы в обычном браузере.

## Озвучка и ограничения

Профессиональный TTS пока не подключён. Подписка на интерфейс сервиса не подтверждает доступ к его API. Текст можно скачать, озвучить в своём сервисе и выбрать полученный аудиофайл в плеере. Аудио не загружается на сервер и не сохраняется после перезагрузки. Пробный SpeechSynthesis зависит от наличия русского голоса на устройстве и может прерываться при сворачивании Telegram или блокировке экрана. Нельзя считать его проверенной фоновой озвучкой для сна.

Истории сейчас короче целевых 16 минут; реальная оценка длительности показана в плеере. Для следующей версии нужны расширенные тексты, больше вариантов, профессиональный TTS с серверным хранением ключа, проверка на реальных iOS/Android и HTTPS-размещение. Нельзя вставлять API-ключ в клиентский JavaScript.

Шрифты Google Fonts и Telegram SDK загружаются внешне; при недоступности шрифтов используются системные. Выборы сохраняются только на текущем устройстве. Склейка фрагментов шаблонная, без генеративной персонализации.
